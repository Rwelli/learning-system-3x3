# Веб-платформа для обучения системам 3×3

Веб-приложение для обучения решению систем трёх линейных уравнений с тремя неизвестными.

## Технологии

- **Backend:** Node.js (Express) + PostgreSQL
- **Frontend:** React + Vite
- **База данных:** PostgreSQL
